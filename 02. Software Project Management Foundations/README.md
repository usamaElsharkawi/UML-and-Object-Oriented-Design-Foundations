# 02. Software Project Management Foundations

Before diving into object-oriented design, it's important to understand how
software projects are managed. This section compares the two dominant
approaches to software development.

## Lectures

1. **Why You Shouldn't Skip This Module** — Why project management matters for
   design work.
2. **Waterfall vs. Agile Software Development Approaches** — A side-by-side
   comparison of the two philosophies.
3. **The Waterfall Model** — A deep dive into the traditional, sequential
   Waterfall methodology.
4. **Agile Software Development** — A deep dive into the iterative, flexible
   Agile methodology.
5. **Waterfall or Agile** — How to decide which approach fits a given project.
6. **How Well Do You Know the Waterfall and Agile Software Development
   Methodologies** — Knowledge-check quiz.

## Key Takeaways

- The differences between Waterfall (sequential) and Agile (iterative).
- Strengths and weaknesses of each methodology.
- How to choose the right approach for your project.
