# 03. Core Object-Orientation Concepts

This section covers the fundamental building blocks of object-oriented
programming — the vocabulary every developer and designer should know.

## Lectures

1. **A Brief History of Programming** — How programming paradigms evolved
   toward object orientation.
2. **Objects** — What an object is and why it's the centerpiece of OO.
3. **The Class** — How classes act as blueprints for objects.
4. **Abstraction** — Focusing on essential qualities while hiding unnecessary
   detail.
5. **Encapsulation and Data Hiding** — Bundling data with behaviour and
   controlling access to internal state.
6. **Inheritance** — Reusing and extending existing classes to model
   hierarchies.
7. **Polymorphism** — Treating different objects through a common interface.
8. **Test Your Knowledge About Fundamentals of OO** — Knowledge-check quiz.

## Key Takeaways

- The four pillars of object orientation: abstraction, encapsulation,
  inheritance and polymorphism.
- How objects and classes relate to each other.
- The historical motivation behind the OO paradigm.
