# 05. UML Basics and Fundamental Diagram Types

This section introduces the Unified Modeling Language (UML) and its most
commonly used diagrams, with challenges and solutions to practise each one.

## Lectures

1. **What's UML** — An introduction to the Unified Modeling Language.
2. **Use Case Diagrams** — Capturing system functionality from the user's
   perspective.
3. **Use Case Diagrams Challenge** — A hands-on exercise.
4. **Use Case Diagrams Solution** — Walkthrough of the challenge solution.
5. **Class Diagrams** — Modelling the static structure of a system.
6. **Class Diagrams Challenge** — A hands-on exercise.
7. **Class Diagrams Solution** — Walkthrough of the challenge solution.
8. **Visibility: Public, Private, Protected, Package** — Access modifiers in
   UML.
9. **Associations** — How classes refer to and relate to one another.
10. **Generalization** — Modelling inheritance relationships.
11. **Dependency, Aggregation, Composition and Realization** — The finer
    relationship types between classes.
12. **Sequence Diagrams** — Modelling object interactions over time.
13. **Activity Diagrams** — Modelling workflows and processes.
14. **Statechart Diagrams** — Modelling state changes of an object.
15. **Test Your UML Skills** — Knowledge-check quiz.
