# 06. Case Study: Designing a Note-Taking App from Scratch

A complete, end-to-end case study that applies everything from the previous
sections to design a real note-taking application using UML.

## Lectures

1. **Practice Makes the Master** — Why hands-on practice matters.
2. **Collecting the Requirements** — Gathering requirements for the note-taking
   app.
3. **Mapping Requirements to User Stories** — Translating requirements into
   agile user stories.
4. **Diagraming the Main Use Cases** — Building the use case diagram for the
   app.
5. **Identifying Classes and Relationships — Epic 1** — Discovering the domain
   classes for the first epic.
6. **Identifying Classes and Relationships — Epic 2 and 3** — Continuing class
   discovery for the remaining epics.
7. **Describing the Flow of Note Creation using Sequence Diagrams** — Modelling
   the runtime interaction for creating a note.
8. **Activity Diagram: Note Management, Local Storage & Cloud Sync** — Modelling
   the workflows for managing and syncing notes.
9. **The Note Object's State Diagram** — Modelling the lifecycle of a Note
   object.
10. **Common Issues in State Machines and How to Fix Them** — Pitfalls and
    fixes when designing state machines.
11. **Case Study (PDF)** — The full written case study for reference.

## Key Takeaways

- A real-world walkthrough from requirements to a complete UML model.
- How each diagram type fits into an overall design.
- Practical tips for avoiding common modelling mistakes.
