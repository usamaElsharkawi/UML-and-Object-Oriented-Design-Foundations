# UML and Object-Oriented Design Foundations

A structured collection of notes and section guides for the
**UML and Object-Oriented Design Foundations** course.

> This repository contains **only the folder structure and a README for each
> section**. The original course media (video lectures, subtitles, images,
> PDFs, etc.) are intentionally excluded.
